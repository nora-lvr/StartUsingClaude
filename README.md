# StartUsingClaude
This is to make the set up more efficient for poeple to start using claude.  The idea is to download a repo that already has a plan to help them set up their computer.

## Getting started

1. **Download this repo.** On GitHub, click the green **Code** button, then
   **Download ZIP**, and unzip it somewhere easy to find (like Documents).
2. **Set up Python for reports (one time only).** Open the `setup` folder and
   double-click:
   - **Windows:** `setup-windows.bat`
   - **Mac:** `setup-mac.command` (if the Mac won't open it, right-click it,
     choose **Open**, then click **Open** again)

   A window will show the progress. It takes a few minutes the first time. It only
   installs things for your own user account and doesn't need an administrator
   password.
3. **Open the folder in Claude.** In the Claude desktop app, go to the **Code** tab
   and choose this folder. Claude reads the instructions in `CLAUDE.md` automatically.
4. **Give Claude your records.** For example, drag in photos of your preg check
   sheets and type: *"Make a preg check report from these photos."* Claude will turn
   them into a spreadsheet (CSV) first, ask you to check it, then build the report.

Your records and reports stay on your computer in the `data` and `reports`
folders. They are never uploaded to this repo.
